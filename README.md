# @kvnloo/dsh-tern

English | [中文](README.zh.md)

A **standalone DeepSeek Harness/Cordis bundle** for an interactive terminal session, with a negotiated Tern Surface Protocol (TSP) semantic surface and ordinary ANSI fallback. It is **not** a trusted Tern runtime plugin and does not own a second Agent or Session. The implementation is extracted from the existing downstream DSH TUI experiment; its history and original [DeepSeek MIT license](LICENSE) are retained.

## Install an exact revision

Requires the published DeepSeek Harness host at **0.2.1-alpha.1**, Node `^22.19.0 || >=24.0.0`, pnpm 11.7.0 for source builds, and a normal installed `dsh` command. This package **has not been published to npm**. Pin an exact reviewed Git commit or an artifact produced from that commit; a floating branch is not a production pin.

```sh
git clone https://github.com/kvnloo/dsh-tern.git
cd dsh-tern
git checkout <reviewed-commit-sha>
corepack enable
pnpm install --frozen-lockfile
pnpm run build
pnpm pack --pack-destination /absolute/private/packages
dsh plugin --profile tui add /absolute/private/packages/<generated-tarball>.tgz
dsh tui
dsh tui --no-native
dsh tui --session-id session-existing
```

The `dsh plugin` command is the **only** supported installer/activator. It initializes an ordinary named `tui` profile, uses the host's package manager and adds `@kvnloo/dsh-tern` after `@deepseek-ai/dsh-base`. The bundled `cordis.patch.yml` registers `@kvnloo/dsh-tern/startup` and `@kvnloo/dsh-tern` via the host's existing patch composer. Start through **`dsh tui`**, never by launching the bundle directly or changing DSH core.

For Git URL installs, pnpm may block a dependency's `prepare` build under its **build-approval** policy. Inspect the exact printed dependency key and approve only the reviewed `@kvnloo/dsh-tern` commit in the profile's `pnpm-workspace.yaml` `allowBuilds` map; then rerun `dsh plugin --profile tui add <pinned-git-spec>`. Do not globally relax approvals. **Built tarballs** contain JS, declarations, the patch YAML and the embedded qualified SDK, and require no consumer-side build approval or patch map.

The standalone `pnpm-lock.yaml` must be generated by the lead using pnpm 11.7.0 and committed after verification; **frozen installs are not yet qualified without that generated lock**. Do not fabricate a lock or release/version provenance.

## Use

Compose multiple turns in a real durable DSH Session. The host owns Agent creation, persisted Session events, tools, approvals, questions and resumption. Both displays consume the same semantic model; live deltas do not become a parallel history. A valid hello/DA1 TSP handshake enables native inline presentation, including a canonical native editor and stable transcript/tool IDs. Invalid/late hello or `--no-native` uses ANSI. The SDK owns PTY framing, credits, ACKs, chunking and terminal restoration.

Use `/help` for available commands. `/model` or `/models` selects from the mounted provider catalog; `/session`, `/sessions`, `/new` and `/resume ID` inspect and adopt eligible root Sessions. `/plan`, `/tasks`, `/jobs`, `/job ID`, `/job-stop ID`, `/agents`, `/agent ID`, `/agent-steer ID TEXT`, `/agent-stop ID`, `/steer TEXT` and `/stop` use existing public services. An approval/question owns input while active and does not silently consume a composer draft.

## Build and test (lead/OMP; unrun in this extraction)

```sh
export DSH_HOST_ROOT=/absolute/checkout/of/kvnloo/deepseek-harness
test "$(git -C "$DSH_HOST_ROOT" rev-parse HEAD)" = 5badb15009ae1756c3afe0ae0cef1faafc290ccc
pnpm install --frozen-lockfile
pnpm run build
pnpm run typecheck
pnpm exec tsc --noEmit -p tsconfig.json
pnpm run test:unit
pnpm run test:public:source
pnpm run test:public:lib
pnpm run test:packed
bash -n tests/host/harness/private_tern.sh
python3 -m py_compile tests/host/harness/*.py
```

The public PTY runners use the host's **actual** CLI/Loader/Agent/Session in **source** and **lib** modes, install the exact packed plugin through `dsh plugin --profile tui add`, and supply only scripted LLM/tool fixtures. Each must run the unchanged **15 public cases**, retry 0 and original deadlines. Host source mode needs its normal generated source aliases; host lib mode needs a real host build. For the signed native capture the host additionally needs its complete, current `.dsh-build/client-build-environment.json` record: a host-only build does not satisfy that check. No provider credentials, inherited daemon, desktop, remote logs, live model, or fake Agent are used.

`tests/host/harness/private_tern.sh` takes the absolute `DSH_HOST_ROOT`, a built host CLI and `DSH_TUI_PACKAGE_TARBALL` (absolute prebuilt tarball). It installs into a private profile, runs normal `dsh tui` inside an owned headless Sway/Tern instance, and records **two** independent identities: the real host Git SHA/build artifact and the standalone plugin Git SHA/packed tarball SHA256. Evidence sealing preserves full wire + metadata + physical Session JSONL under an owner-only allowlist with redaction and immutable hashes. Replay-only and remote-uncollected are never claimed as live local evidence. See [private harness documentation](tests/host/harness/README.md).

The packed consumer gate checks built-to-packed bytes, installs in a fresh npm consumer and compares the embedded patched SDK against **public unpatched registry 0.1.0** as a required negative control. Set `REGISTRY_TERN_TARBALL` only to an independently obtained raw 0.1.0 tarball when offline.

## SDK, provenance and license

- `@stencil-hq/tern@0.1.0` is pinned **exactly**. The checked-in pnpm patch `patches/@stencil-hq__tern@0.1.0.patch` has qualified SHA256 `c222b3495ade7f7b334ae4f5f94be05b2b4edb2764645dd1972f90ad436e0998`. The production build inlines the **patched** SDK, so consumers cannot silently resolve an unpatched copy. Changing that patch requires a new real witness.
- Original Tern/TSP authors: **Can Bölük / Stencil Labs**. DSH/Cordis Agent, Session and plugin seams: **DeepSeek Harness/Cordis contributors**. Comparative native surfaces: **Hermes Agent contributors** and [Hermes x Tern](https://github.com/kvnloo/hermes-tern), especially `frontend/src`, and [Hermes preview/tern-frontend](https://github.com/kvnloo/hermes-agent/tree/preview/tern-frontend/ui-tsp). This bundle reuses the SDK rather than implementing a replacement protocol.
- Repository [LICENSE](LICENSE) retains DeepSeek's original MIT grant; SDK notices are in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). The SDK is MIT-licensed and must remain attributed.
- [Authoritative RFC #6](https://github.com/kvnloo/deepseek-harness/issues/6) and [standalone tracking issue #1](https://github.com/kvnloo/dsh-tern/issues/1) define acceptance.

This extracted package is **not yet certified**. OMP still must generate canonical lock/language records, execute the full exact-head MBP gates, and complete signed-window native pointer/approval/detach, owned daemonless API submission and Hermes/OMP differential capture. Tern 0.9.5 daemon-backed `cx.session:event` reports `no program runs in that pane` despite a working native UI; do **not** infer a passing daemon-backed API test from native UI success.
